Architecture / JEV integration

A request.
A judgment.
A deliberate next step.

How Modex turns a request into a coding turn, and where JEV informs the decisions along the way.

JEV judgment & policyCoding agent & executionFallback & human review
01

Route the request

Auto asks JEV for typed judgments. Local policy converts those judgments into a backend, model, reasoning effort, and fast-mode choice.

Session continuity matters. Backend switching requires permission in policy and no existing CLI session.


02
Let the coding agent work
Claude or Codex selects individual tools during the turn. JEV informs routing and approvals; the coding CLI runs the work.
Routing privacy. JEV receives clipped request/history digests and project facts, without file contents, diffs, or tool output.


03
Judge a proposed action
The approval gate combines exact-match rules with optional JEV judgments, then applies safety downgrades before returning a decision.
Failure behavior. If JEV fails, only deterministic matches count. No matching rule defaults to asking the user.
